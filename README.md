# Scientific Friday Bar - projects

[Scientific Friday Bar](https://scifbar.dk) is a recurring, informal session connecting
organizations with concrete AI use cases and data scientists who want to work on real problems.
Some discussions do not end with the write-up. They turn into a prototype: a small, concrete
thing that a participant can put in front of their colleagues and correct. This repo is the
public list of those prototypes.

Each project lives in its own private repository under the scifbar organization. Everyone can
see here that a project exists, who it is for and what question it is trying to answer. Only
the people working on a project have access to its repository. As a project grows, people
from the scifbar community are invited in as contributors.

## How a project starts

1. A discussion at a scifbar event, or a follow-up meeting, produces a one-page brief: who the
   prototype is for, what it should show on the first page and on the last page, and what is
   deliberately left out.
2. A first version is built from the brief, usually within a week, and shared as a link.
3. The person it is for corrects it. The correction becomes the next brief. Repeat.

The first version is never the product. It exists so that the right people can say "no, not
like that, like this". That is the point.
